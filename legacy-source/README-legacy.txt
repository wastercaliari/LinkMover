LinkMover - aplicativo Windows

Execute LinkMover.exe. O Windows exibira o pedido de permissao administrativa.
Selecione a pasta atual do software e depois o diretorio pai no disco de destino.
O destino final sera <diretorio escolhido>\<nome da pasta original>.
Feche o software antes de mover e confirme os caminhos exibidos.

O app verifica se o destino ja existe, copia os arquivos, compara a contagem e o tamanho
total, renomeia temporariamente a origem e cria o link simbolico no caminho original.
Em caso de falha, tenta restaurar a origem e preserva dados quando o estado e incerto.

Recomendacao: teste primeiro com uma pasta descartavel e mantenha backup dos dados importantes.
